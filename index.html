GEOGRAPHY OF LINE ARRANGEMENTS

A browser-based research lab for pure mathematics

G.L.A Research Lab combines an interactive SageMath workspace with a place to share selected mathematical notes and findings. Its current focus is projective line arrangements: initialize the engine to investigate incidence structures, compute logarithmic Chern invariants, explore parameter families, and develop experiments in linked Sage cells. The Latest Notes section presents curated research updates.

HOW IT WORKS

One engine, one shared research session

01 Initialize

The original engine is loaded, SHA-256 checked, and executed in a SageMathCell kernel.

02 Research

Every notebook cell is linked to that same kernel, so functions and variables defined earlier remain available later.

03 Preserve

Cell source is saved in your browser. Export useful work as a .sage file whenever you want a portable copy. ('Export cells' button at the top)

ENVIRONMENT

Research model

Intended purpose

The notebook is intended for broad computational work on projective line arrangements: incidence structures, multiplicity distributions, logarithmic Chern invariants, parameter families, and asymptotic experiments. This is the first of many Research Labs, so bugs are encouraged to be reported.

Session model

The live Sage kernel is temporary. Reloading or resetting starts a new kernel, but the source of your research cells remains saved locally in the browser. This means your cells are auto-saved.

Internet requirement

The frontend is a static webpage. Sage evaluations are executed by the public SageMathCell service, so computation requires an internet connection.

Usage instructions

To use, one must first initialize the math engine. Afterwards, simply create cells and enter python code into them before running. Guide yourself using the function manual above, as many of these functions are useful for research. However, it is encouraged to use your own functions as well.
